## 我的 Neovim 速查表

leader 键 = 空格       <leader>e 就是「按空格，再按 e」

## 文件树
空格 e          开关文件树
空格 o          聚焦文件树

## 标签
空格 1~9        跳到第 N 个 buffer
空格 b n        下一个 buffer
空格 b p        上一个 buffer
空格 b d        关闭当前 buffer
空格 b o        关闭其它 buffer
空格 b l        关闭右侧 buffer
空格 b h        关闭左侧 buffer
Shift+l/h       下一个 / 上一个 buffer
空格 q q        退出全部

## 分屏
----------------------------------------------------------------
空格 s v        左右分屏
空格 s h        上下分屏
空格 s c        关闭当前分屏
空格 s x        只保留当前分屏
Ctrl+h/j/k/l    在分屏间切换
Ctrl+方向键     调整分屏大小


## 终端
----------------------------------------------------------------
空格 t f        浮动终端
空格 t h        横向终端
空格 t v        纵向终端
Ctrl+\          开关终端
（终端里按 Esc 回普通模式）


## 退出
----------------------------------------------------------------
:q              智能退出（没未保存改动就一次退干净）
空格 q          同上
空格 q q        无条件退出全部


## 保存与编辑
----------------------------------------------------------------
Ctrl+s          保存
Esc             取消搜索高亮
u               撤销
Ctrl+r          重做
空格 s o        数字排序（选中行）
空格 s O        字典排序（选中行）


## 复制、剪切与粘贴
----------------------------------------------------------------
选择
v               字符选择（按方向键扩展）
V               整行选择
Ctrl+v          块选择（矩形，选列）
ggVG            全选

复制
y               复制选中的内容
yy              复制当前整行（不用先选）
3yy             往下复制 3 行
y$              复制到行尾
yw              复制一个单词

剪切
d               剪切选中的内容（可视模式）
dd              剪切当前整行
3dd             往下剪切 3 行
dw              剪切一个单词
D               剪切到行尾
x               剪切一个字符

粘贴
p               粘贴（整行内容粘到下一行）
P               粘贴到光标前 / 上一行

路径（自定义）
空格 y p        复制文件完整路径
空格 y d        复制所在目录
空格 y n        复制文件名
空格 y r        复制相对路径

说明
clipboard = unnamedplus，所以 y 复制、d 剪切之后
都可以直接粘到浏览器、微信等地方。
从外部粘进来用 p，不要用 Ctrl+V（缩进会乱）。

不想让删除污染剪贴板时，用黑洞寄存器：
"_dd            删除整行但不覆盖剪贴板
"_d             删除选区但不覆盖剪贴板


## 查找与替换
----------------------------------------------------------------
/               向下搜索
?               向上搜索
n / N           下一个 / 上一个匹配
*               搜索光标所在的单词
:s/旧/新        替换当前行第一个
:s/旧/新/g      替换当前行全部
:%s/旧/新/g     替换整个文件
:%s/旧/新/gc    替换前逐个确认


## 插入模式
----------------------------------------------------------------
jj              退出插入模式（代替 Esc）
Alt+h/j/k/l     左 / 下 / 上 / 右 移动光标
Alt+a / Alt+e   跳到行首 / 行尾
方向键          也能直接移动（原生支持）

说明：不用先按 Esc 再移动了，直接在插入模式里按上面这些。


## 插件
----------------------------------------------------------------
:Lazy           插件管理（I 装 / U 更新 / S 同步 / X 清理）
:Mason          装 LSP / 格式化工具
:checkhealth    体检
:Lazy log       插件出错看这个


## 帮助
----------------------------------------------------------------
:Help           打开本文件（可直接编辑，保存即生效）
:CheatView      浮窗只读查看
:CheatAuto      自动生成的完整按键表
:HelpReal       真正的 Neovim 帮助文档
:h <主题>       如 :h lsp
