## 我的 Neovim 速查表

leader 键 = 空格       <leader>e 就是「按空格，再按 e」

## 编辑与撤销
----------------------------------------------------------------
Ctrl+s          保存
u               撤销
Ctrl+r          重做（撤销撤多了）
Esc             取消搜索高亮
空格 s o        数字排序（选中行）
空格 s O        字典排序（选中行）

删除全部内容
ggdG            删掉整个文件内容（gg 到开头，dG 删到结尾）
ggVG 然后 d     全选再删（和上面效果一样）
:%d             命令形式

删除后恢复
u               撤销
Ctrl+r          重做


## 移动
----------------------------------------------------------------
上下移动
Ctrl+d / Ctrl+u     半屏 下 / 上（最常用）
Ctrl+f / Ctrl+b     整屏 下 / 上
20j / 20k           往下 / 上 20 行
j / k               下一行 / 上一行

跳到指定位置
gg / G              文件开头 / 结尾
50G 或 :50          跳到第 50 行
0 / ^               行首 / 行首第一个非空白
$                   行尾
w / b               下一个 / 上一个单词
{ / }               上一个 / 下一个空行（段落）
%                   跳到匹配的括号

屏幕内定位（不滚动）
H / M / L           屏幕 顶部 / 中间 / 底部

搜索着跳
/关键词             向下搜索
n / N               下一个 / 上一个匹配
*                   搜索光标所在的单词


## 复制、剪切与粘贴
----------------------------------------------------------------
选择
v               字符选择（按方向键扩展）
V               整行选择
Ctrl+v          块选择（矩形，选列）
ggVG            全选

复制
y               复制选中的内容
yy              复制当前整行（不用先选）
3yy             往下复制 3 行
y$              复制到行尾
yw              复制一个单词

剪切 / 删除
d               剪切选中的内容（可视模式）
dd              剪切当前整行
3dd             往下剪切 3 行
dw              剪切一个单词
diw             剪切光标所在的整个单词
D               剪切到行尾
dG              剪切到文件尾
dgg             剪切到文件头
x               剪切一个字符

粘贴
p               粘贴（整行内容粘到下一行）
P               粘贴到光标前 / 上一行

路径（自定义）
空格 y p        复制文件完整路径
空格 y d        复制所在目录
空格 y n        复制文件名
空格 y r        复制相对路径

说明
clipboard = unnamedplus，所以 y 复制、d 剪切之后
都可以直接粘到浏览器、微信等地方。
从外部粘进来用 p，不要用 Ctrl+V（缩进会乱）。

不想让删除污染剪贴板时，用黑洞寄存器：
"_dd            删除整行但不覆盖剪贴板
"_d             删除选区但不覆盖剪贴板
"_diw           删除单词但不覆盖剪贴板


## 查找与替换
----------------------------------------------------------------
/               向下搜索
?               向上搜索
n / N           下一个 / 上一个匹配
*               搜索光标所在的单词
:s/旧/新        替换当前行第一个
:s/旧/新/g      替换当前行全部
:%s/旧/新/g     替换整个文件
:%s/旧/新/gc    替换前逐个确认


## 插入模式
----------------------------------------------------------------
jj              退出插入模式（代替 Esc）
Alt+h/j/k/l     左 / 下 / 上 / 右 移动光标
Alt+a / Alt+e   跳到行首 / 行尾
方向键          也能直接移动（原生支持）

说明：不用先按 Esc 再移动了，直接在插入模式里按上面这些。


## 文件树
----------------------------------------------------------------
开关与导航
空格 e          开关文件树
空格 o          聚焦文件树
j / k           上下移动
l / <CR> / o    打开（展开文件夹 / 打开文件）
h               折叠父目录
v / s           垂直 / 水平分屏打开
P               关闭树但不切换焦点
R               刷新
f               实时过滤（边打边筛）
S               在树里搜索文件
H               显示/隐藏点文件
g?              查看树内全部按键

单个文件操作
a               新建文件 / 文件夹
                输入 "abc.txt" = 建文件
                输入 "mydir/"  = 建文件夹
r               重命名 / 移动（改完整路径）
                例：C:\proj\src\a.txt -> C:\proj\lib\a.txt
                注意：目标文件夹必须已存在，不会自动创建
e               只改文件名（保留扩展名，不挪位置）
d 或 D          移到回收站（可在资源管理器里还原）
<Del>           彻底删除（不进回收站，找不回来）
x               剪切（配合 p 粘贴 = 移动）
c               复制（配合 p 粘贴 = 复制）
p               粘贴
y               复制文件名
Y               复制相对路径
gy              复制绝对路径

多个文件一起移动（方法一：视觉模式）
V               进入行选择
j / k           扩展选中的范围
x               剪切所有选中项
                移到目标文件夹上
p               粘贴 = 全部移动过去
（选中的是文件夹时，里面的内容会一起搬走）

多个文件一起移动（方法二：标记）
m               标记 / 取消标记当前项（可标记多个）
bmv             移动所有已标记的项（会问移到哪）
bd              删除所有已标记的项
bt              移到回收站（所有已标记的项）
（m 标记后在文件名前有记号，便于跨目录挑选）

（注意：这些键只在文件树窗口里生效，不影响普通编辑）

## 标签
空格 1~9        跳到第 N 个 buffer
空格 b n        下一个 buffer
空格 b p        上一个 buffer
空格 b d        关闭当前 buffer
空格 b o        关闭其它 buffer
空格 b l        关闭右侧 buffer
空格 b h        关闭左侧 buffer
Shift+l/h       下一个 / 上一个 buffer
空格 q q        退出全部

## 分屏
----------------------------------------------------------------
空格 s v        左右分屏
空格 s h        上下分屏
空格 s c        关闭当前分屏
空格 s x        只保留当前分屏
Ctrl+h/j/k/l    在分屏间切换
Ctrl+方向键     调整分屏大小


## 终端
----------------------------------------------------------------
空格 t f        浮动终端
空格 t h        横向终端
空格 t v        纵向终端
Ctrl+\          开关终端
（终端里按 Esc 回普通模式）


## 退出
----------------------------------------------------------------
:q              智能退出（没未保存改动就一次退干净）
空格 q          同上
空格 q q        无条件退出全部


## 插件
----------------------------------------------------------------
:Lazy           插件管理（I 装 / U 更新 / S 同步 / X 清理）
:Mason          装 LSP / 格式化工具
:checkhealth    体检
:Lazy log       插件出错看这个


## 帮助
----------------------------------------------------------------
:Help           打开本文件（可直接编辑，保存即生效）
:CheatView      浮窗只读查看
:CheatAuto      自动生成的完整按键表
:HelpReal       真正的 Neovim 帮助文档
:h <主题>       如 :h lsp
