## 终端
----------------------------------------------------------------
打开与关闭
Ctrl+\          开关终端（同一个键打开/关闭）
空格 t f        浮动终端
空格 t h        横向终端
空格 t v        纵向终端
空格 t q        彻底关闭终端（结束 shell 进程，下次是全新的）

从终端回到普通模式
Esc 或 jj       两个都行，按一下就回到普通模式
                然后就能用 :q 之类的普通模式命令
                （终端里是「终端模式」，和编辑时的「插入模式」是两套按键表，
                  所以 jj 要单独配一遍才生效）

窗口间移动
Ctrl+h/j/k/l    切到左/下/上/右窗口

说明
· Ctrl+\ 关闭终端时**不杀 shell 进程**，下次打开是瞬时的，
  之前敲过的命令和当前目录都还在
· 想彻底重置环境（目录回到默认、清空输出）用 空格 t q
· 终止终端里正在跑的程序用 Ctrl+c
· 在终端里敲 exit 也会退出 shell 并自动关窗

⚠️ 为什么终端里 Ctrl+\ 不生效
Neovim 里 <C-\> 是终端模式的「转义前缀」，原生的
<C-\><C-n> 用来退出终端模式。若把 Ctrl+\ 也映射到终端模式，
这条逃生通道就断了，会卡在终端里出不来。
所以 Ctrl+\ 只在普通/插入模式生效，在终端里退出请按 Esc。


## 编译运行（C / C++）
----------------------------------------------------------------
空格 r r        编译当前文件 + 运行（最常用）
空格 r c        只编译（看错误用）
空格 r o        只运行（用上次编译的 exe，不重新编译）

行为说明
· 自动先保存再编译，不会编译到旧版本
· 编译器 C:\mingw64\bin\gcc.exe（MinGW-W64 16.2.0）
· 参数 -std=c17 -Wall -Wextra（开警告，能提前发现笔误）
· 生成的 exe 和源文件同目录、同名
· 编译失败时错误进 quickfix，自动打开错误列表
    用 :cnext / :cprev 在错误之间跳
    :copen / :cclose 开关错误列表
· 运行用浮动终端，所以 scanf 这类需要输入的程序能直接交互
· 只有 .c / .cpp / .cc / .cxx 文件能触发，别的文件会提示

例子（你的练习文件）
打开 1.hello_word.c，按 空格 r r
→ 编译成 1.hello_word.exe 并立即运行

## 代码提示（LSP）
----------------------------------------------------------------
适用文件：C / C++（clangd）。打开 .c / .cpp 文件后自动生效。

跳转与查看
gd              跳转到定义
gD              跳转到声明
gr              查看所有引用（改代码前先看谁在用）
gi              跳转到实现
gt              跳转到类型定义
K               查看文档（函数签名、注释）

编辑
空格 l r        重命名符号（安全地改函数名/变量名）
空格 l a        代码操作 / 快速修复
空格 l f        格式化（clang-format）
空格 l d        查看当前行的错误详情

诊断（错误提示）
]d              下一个错误 / 警告
[d              上一个错误 / 警告
                红字在行尾显示，符号列有 E / W 标记

补全（插入模式下）
Ctrl+Space      手动弹出补全菜单
Ctrl+n / Ctrl+p 下一个 / 上一个候选
Ctrl+y          接受选中的候选
Ctrl+e          关闭补全
Tab             跳下一个占位符（函数参数之间）
Enter           接受补全

说明
第一次打开项目时 clangd 要建索引，跳转可能几秒后才准。
索引缓存在项目里，第二次打开就快了。
如果找不到标准库头文件，在项目根目录放一个
compile_commands.json（用 bear 或 cmake 生成）。

格式化与 tab 缩进
空格 lf 走的是 clang-format，它的默认风格是「2 个空格缩进」，
会把 tab 全换成空格。配置目录里放了 .clang-format
（UseTab: Always），格式化前会自动临时放到项目目录，
所以格式化完仍然是 tab 缩进，不会变成空格。
如果你的项目里自己有 .clang-format，那个优先，不会被覆盖。
